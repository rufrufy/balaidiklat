## Archived: 2026-08-10
### Architecture Decisions
- WhatsApp bot pakai KirimChat webhook API. Controller: KirimChatWebhookController. State machine via WhatsappSession.state + ChatbotRule.
- Bot menu pakai interactive list (sendMainMenu). Menu ID 6 = Customer Care.
- Session storage: DB table whatsapp_sessions (per phone_number).
- Outbound WA: App\Services\KirimChatService (sendText/sendList/sendButtons/sendImage).
- Mode bot vs human: kolom whatsapp_sessions.mode ('bot'|'human') + human_taken_at.
- Provider switch: kirim.chat (lama) -> kirimdev (baru). API = Meta WhatsApp Cloud API style.
- Lama: POST /messages/send body {phone_number,channel,message_type,content}. Baru: POST /v1/{phone_number_id}/messages body {messaging_product,to,type,text/interactive}.
- API key format beda: kc_live_ (lama) vs kdv_live_ (baru). Key lama TIDAK valid.
- Webhook kirimdev: daftar via POST /v1/webhook_subscriptions {url,events:[message.received],phone_number_ids}. initial_secret di response = signing secret.
